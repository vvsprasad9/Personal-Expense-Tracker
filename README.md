# Personal Expense Tracker

A MERN stack application to manage daily expenses with authentication.

## Tech Stack
- React
- Node.js
- Express
- MongoDB

## Features
- Login & Register
- Add and manage expenses
- Expense summary

## Project Structure
client/ - React frontend  
server/ - Express backend  

## Prerequisites
- Node.js
- npm
- MongoDB

## Environment Variables
Create `server/.env`:
PORT=5000  
MONGO_URI=your_mongodb_uri  
JWT_SECRET=your_secret  

## Run Locally

### Backend
cd server  
npm install  
npm start  

### Frontend
cd client  
npm install  
npm start
